## 📌 Sobre o projeto

A Calculadora de Consumo Elétrico é um programa desenvolvido em Python que permite estimar o consumo mensal de energia elétrica de um aparelho.

O usuário informa o nome do aparelho, sua potência em watts e o tempo médio de utilização diária. Com essas informações, o programa calcula o consumo estimado em kWh por mês.

## 🎯 Objetivo

O objetivo do projeto é praticar conceitos básicos de programação estruturada, entrada e saída de dados e cálculos matemáticos utilizando Python.

## 🛠️ Tecnologias utilizadas

- 🐍 Python
- 💻 Visual Studio Code
- 🐙 Git
- 🌐 GitHub

## 🧮 Fórmula utilizada

O consumo mensal é calculado utilizando a seguinte fórmula:

```text
consumoMensal = (potencia × horasDia × 30) / 1000
```

## ▶️ Como executar

1. Instale o Python.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o terminal.
4. Execute o comando:

```bash
python app.py
```

5. Informe o nome do aparelho, a potência em watts e o tempo médio de uso diário.
